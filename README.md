# My Portfolio

A modern, responsive portfolio website built with React, Vite, and Tailwind CSS, designed around a Cloud Operations Center theme to showcase my journey as an aspiring Cloud & DevOps Engineer.

**Live Website:**  
https://my-portfolio-website-sigma-ebon.vercel.app/

---

## About

This portfolio highlights my technical skills, projects, certifications, and career journey. It features a custom interface inspired by cloud infrastructure dashboards, smooth animations, and a functional contact form.

---

## Features

- Responsive design
- Cloud Operations Center themed interface
- Animated boot sequence
- Interactive command palette
- Resume download
- Project showcase
- Certificate gallery
- Contact form powered by EmailJS
- Smooth animations using Framer Motion

## Installation

Clone the repository:

```bash
git clone https://github.com/Jai-This-Side/My-Portfolio.git
```

Navigate to the project directory:

```bash
cd My-Portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build the project:

```bash
npm run build
```
